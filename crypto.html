How to add your tracker
If your tracker is a browser-based HTML/CSS/JS app, unzip it into /crypto/ and make sure the main file is /crypto/index.html.
If you only want a downloadable ZIP, place the file at /files/crypto-tracker.zip.
You can do this directly in GitHub: Add file → Upload files → Commit.
